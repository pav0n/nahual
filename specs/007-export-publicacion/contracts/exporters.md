# Contrato: exportadores (007)

Funciones puras de `packages/domain/src/export/` (research R2–R8). Entrada: `ExportSource[]` ya
redactado o no ([data-model.md](../data-model.md)); salida: `ExportResult`. Deterministas
(FR-017): el único dato variable (`capturedAt`) solo aparece en comentarios de MSW y Postman
cuando el dev incluye la respuesta, nunca en el código ejecutable.

```ts
export type ExportFormat = "curl" | "fetch" | "vitest" | "msw" | "zod" | "postman";
export interface ExportOptions { appVersion: string; includeSensitive: boolean }
export function exportAs(format: ExportFormat, sources: ExportSource[], options: ExportOptions): ExportResult;
export const FORMATS: Record<ExportFormat, { extension: string; needsResponse: "no" | "optional" | "json"; batch: boolean }>;
```

## Primer comentario de cada archivo

`// Generated by Nahual <versión> · <herramienta> <mayor>` (cURL: `# Generated by …`). Vitest añade
`// Environment variables required: …` cuando hay valores redactados. Postman no lleva comentario
(JSON); lleva `info.description` con el mismo texto.

## cURL (`curl.ts`)

```sh
# Generated by Nahual 1.0.0
curl 'http://127.0.0.1:4311/api/items?page=1&token=<redacted>' \
  -X POST \
  -H 'accept: application/json' \
  -H 'authorization: <redacted>' \
  -H 'content-type: application/json' \
  --data-raw '{"name":"x","password":"<redacted>"}'
```

- `-X` solo si el método no es `GET` (o es `GET` con body).
- Headers en minúsculas, en el orden capturado, sin los que pone el navegador (`forbidden-headers`
  salvo `cookie` y `referer`).
- Body `form` ⇒ `--data-urlencode`; `multipart` ⇒ `-F name=value` por parte de texto y
  `# omitted file part: <filename>` por archivo; `omitted` ⇒ `# body omitted: <reason> (<size>)`.

## fetch (`fetch.ts`)

```ts
// Generated by Nahual 1.0.0
const response = await fetch("http://127.0.0.1:4311/api/items?page=1", {
  method: "POST",
  headers: { accept: "application/json", authorization: "<redacted>", "content-type": "application/json" },
  body: JSON.stringify({ name: "x", password: "<redacted>" }),
});
const data = await response.json(); // captured: 200 application/json
```

Body JSON válido ⇒ `JSON.stringify(objeto)` con el objeto literal; otro texto ⇒ cadena literal;
`form` ⇒ `new URLSearchParams({...})`; `multipart` ⇒ `FormData` con `append`.

## Pruebas

- Propiedades: ningún `ExportResult.code` contiene un valor redactado cuando
