# Registro de decisiones de arquitectura (ADR)

Decisiones transversales que no pertenecen a una sola feature. Las decisiones propias de una
feature siguen en el `research.md` de su carpeta en `specs/`.

Cada ADR tiene contexto, decisión, alternativas descartadas, consecuencias y cuándo revisarla. No
se reescribe: si una decisión cambia, se añade un ADR nuevo que la reemplaza y se marca la
anterior como "Reemplazada por ADR NNNN".
